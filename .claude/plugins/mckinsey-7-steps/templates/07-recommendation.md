- [ ] 与决策者确认过这份建议书

## 反模式（红旗）

| 红旗信号 | 真相 |
| --- | --- |
| 建议是"需要进一步研究" | 等于没建议；至少给出"基于现有证据的暂定建议" |
| 没有"我们不建议什么" | 决策者会问为什么不做 X，提前回答 |
| 实施路径没有决策门 | 这不是建议，是单程票 |
| KPI 全是滞后指标（如年收入） | 加先行指标（如周活、转化率），才能早预警 |
| Next 7 Days 写"启动项目" | 太空，写到具体会议、文件、邮件 |
| 风险栏写"市场不确定性" | 万能套话，写到具体场景和阈值 |
