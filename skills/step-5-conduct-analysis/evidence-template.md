# 第 5 步：佐证数据档（Evidence Log）

> 复制本模板到 `docs/strategy/<项目代号>/step-5-evidence.md`，与 `step-5-analysis.md` 并行维护。
> analysis 文档放结论与推理，本档案放原始数据与来源——三个月后回看，结论可能被推翻，但证据不能丢失。
> 所有可下载的佐证材料原件保存在同级 `evidence/` 目录，本档案通过文件路径列和 §6 文件索引表指向对应原件。

## 反模式（红旗）

| 红旗信号 | 真相 |
| --- | --- |
| 只有数字、没来源 | 不可追溯 = 不可信，强制补出处 |
| 全部标 A 或全部标 C | 等级混乱，按真实出处分类 |
| 待回填清单为空 | 案头分析不可能覆盖所有内部数据，要么诚实列出，要么 step-7 立项时翻车 |
| 数据风险章节写"无" | 任何数据都有局限，强制列 ≥ 3 条 |
| "本地存档"列全部空白 | 佐证材料未实际下载；链接会失效，必须存档原件 |
| `evidence/` 有文件但 §6 索引表无记录 | 孤立文件无法溯源；每个文件必须在索引表有对应行 |
| §6 索引表有记录但 `evidence/` 无对应文件 | 空引用；要么文件未下载，要么路径写错 |
