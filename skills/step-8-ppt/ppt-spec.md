# PPT 版式规格(默认)

> 本文档是 step-8-ppt 的**默认版式规格**。如需调整,改 `build_ppt.py` 顶部的 `THEME` / `FONT_*` 常量,而不是去 PPT 文件里手改。

## 1. 画布

- **比例**:16:9 宽屏
- **尺寸**:13.333 inch × 7.5 inch (默认 PowerPoint 宽屏)
- **背景色**:纯白 #FFFFFF

## 2. 字体

| 类别 | 字体 | 备注 |
| --- | --- | --- |
| 中文 | **微软雅黑 (Microsoft YaHei)** | East Asian face,通过 `<a:ea typeface=...>` 绑定 |
| 拉丁 | **Microsoft YaHei** | 中英统一,避免回退到 Calibri/Arial |
| 字符备份 | 无衬线系列(SimHei / 黑体) | 仅在目标终端缺微软雅黑时回退 |

## 3. 字号档位

| 用途 | 字号 (pt) | 加粗 |
| --- | --- | --- |
| 封面主标题 | 36 | 是 |
| 封面副标题 | 18 | 否 |
| 页面标题 (page header H1) | 24-28 | 是 |
| 页面副标题 (sub) | 13-14 | 否 |
| 段落标题 / 强调小标题 | 14-16 | 是 |
| 正文 | 11-12 | 否 |
| 表格表头 | 11 | 是,白字 |
| 表格正文 | 10-11 | 否 |
| 数据高亮(关键数字) | 22-32 | 是,#D80C18 |
| 注脚 / 元信息 | 9 | 否,#7F7F7F |

**下限**:正文 ≤ 8pt 不可接受;投影会糊。

## 4. 配色

| 角色 | HEX | RGB | 用途 |
| --- | --- | --- | --- |
| **主色 PRIMARY** | `#1E53A4` | (30, 83, 164) | 蓝色,标题底色、表头、装饰条、主立场结论 |
| **强调 HIGHLIGHT** | `#D80C18` | (216, 12, 24) | 红色,关键数字、风险高亮、决策门 STOP 条件 |
| 辅助灰深 GRAY_DARK | `#404040` | (64, 64, 64) | 正文文字 |
| 辅助灰中 GRAY_MID | `#7F7F7F` | (127, 127, 127) | 副标题、注脚 |
| 辅助灰浅 GRAY_LIGHT | `#E6E6E6` | (230, 230, 230) | 块底、分隔线、表格交替行 |
| 强调浅红 HIGHLIGHT_BG | `#FFF2F3` | (255, 242, 243) | 风险栏 / P 列底色 |
| 主色浅蓝 PRIMARY_BG | `#EAF1F9` | (234, 241, 249) | 高亮区块底色 |
| 白 WHITE | `#FFFFFF` | (255, 255, 255) | 表头白字、画布底 |

**红色不滥用**:每页 ≤ 3 处红色元素。红色的稀缺性 = 注意力。

## 5. 边距与栅格

- 左 / 右页边距:0.55"
- 顶 / 底页边距:0.55"
- 三栏布局:每栏宽 ≈ 4.0",栏间距 0.2"
- 表格行高:0.55-0.7"

## 7. 视觉装饰约束

- **禁用**:阴影、渐变、3D、艺术字、图标包大量装饰
- **允许**:实心矩形(色块)、细线分隔(0.75-1.5 pt)、简单柱状图(纯色填充)
- **图表**:数据点直接写数字,不依赖图例;轴线 ≤ 0.75 pt 灰色

## 8. 中文字体绑定的实现注意

python-pptx 的 `font.name = "Microsoft YaHei"` 只写 `<a:latin>`,不写 `<a:ea>`。中文会回退到主题默认字体。
**必须**在每个 run 的 `<a:rPr>` 里手动加上:

```xml
<a:ea typeface="Microsoft YaHei"/>
```

模板的 `set_run(run, text, ...)` 已实现此逻辑,**所有写文本都走 `set_run`,不要直接 `tf.text = "..."`**。
