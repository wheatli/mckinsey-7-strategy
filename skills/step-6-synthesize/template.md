## 自检清单（完成门禁）

- [ ] 主结论是封闭式的（yes/no 或具体选项）
- [ ] 论点 = 3（不多不少；如果一定要 2 或 4，写明理由）
- [ ] 每个论点都是 MECE 的
- [ ] 每个论点都至少有 1 个 step-5 的实证支持
- [ ] 至少做了 2 条红队反对意见的回应
- [ ] 主结论一句话能让外行听懂

## 反模式（红旗）

| 红旗信号 | 真相 |
| --- | --- |
| 主结论是 "需要进一步研究" | 没结论；至少给出"在条件 X 下倾向 Y"的判断 |
| 论点是数据描述 | 应是判断（"市场已饱和"），不是描述（"市场份额是 60%"） |
| 反对意见栏空着 | 你只在自我证实；红队是必须的 |
| 论点之间互相重叠 | MECE 没做好，重新合并或拆分 |
| 论点和论据用错位 | "因为 H1 所以 H1" 这种循环论证 |
