## 反模式（红旗）

| 红旗信号 | 真相 |
| --- | --- |
| 所有假设都"证实" | 你在做证实而非证伪，回去找反例 |
| 反向证据栏写"无" | 没找过，至少花 30 分钟主动找一次 |
| So What 写成"X 是 Y" | 那是数据不是结论；So What 必须回到焦点问题 |
| 数据精确到小数点后 4 位 | 假精确，输出精度应匹配输入精度 |
| 没有意外发现 | 要么没看仔细，要么没记录——分析中一定会有意外 |
